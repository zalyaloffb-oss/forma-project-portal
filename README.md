# Форма — публичный демонстрационный сайт

Библиотека проектов и 3D-просмотрщик. Статический сайт для GitHub Pages.

Демо публичное, приглашения не защищают доступ. Добавленные через интерфейс проекты и PDF сохраняются только в браузере посетителя и не синхронизируются между устройствами. В комплекте демонстрационные записи и модель «Территория здоровья v23». Исходный F3D не включён.

Для публикации выберите Settings → Pages → GitHub Actions. Workflow публикует сайт при обновлении main.

## Инструменты 3D

«Плоскости» выделяет связную плоскую грань сетки и показывает площадь. «Сечение от грани» задаёт плоскость среза; смещение в миллиметрах идёт вдоль нормали (отрицательное — внутрь), «Обратить» меняет видимую сторону. Замкнутые контуры среза заполняются цветной штриховкой по телам, отверстия сохраняются. Незамкнутая или повреждённая сетка может не образовать заливку.

«Двигать тело» позволяет перетаскивать отдельное тело левой кнопкой в плоскости экрана. Перемещения временные; «Вернуть тела», «Сброс» и изменение разнесения восстанавливают положения. Исходная CAD-модель не изменяется.
