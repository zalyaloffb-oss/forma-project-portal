# Форма — публичный демонстрационный сайт

Библиотека проектов и 3D-просмотрщик. Статический сайт для GitHub Pages.

Демо публичное, приглашения не защищают доступ. Добавленные через интерфейс проекты и PDF сохраняются только в браузере посетителя и не синхронизируются между устройствами. В комплекте демонстрационные записи и модель «Территория здоровья v23». Исходный F3D не включён.

Для публикации выберите Settings → Pages → GitHub Actions. Workflow публикует сайт при обновлении main.
