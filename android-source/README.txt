Форма Android 1.0.3 (code4). Каталог и проверка обновлений перенесены на HTTPS GitHub Pages. Нативная библиотека + WebView 3D. Первая установка этой версии поверх старой вручную: прежняя версия не может получить уведомление с недоступного Beget. Последующие версии проверяются по /android/release.json на GitHub. Ключ подписи сохранён прежним и никогда не находится в репозитории. Официальные JDK21, SDK36/build-tools36 в ~/.cache/forma-android-tools. python build.py. После сборки копируйте APK/release.json/SHA256.txt из output в ../android и публикуйте через Git. Проверка на физическом Pixel ещё не выполнена.
